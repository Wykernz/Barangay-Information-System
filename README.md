# Barangay Information System

A LAN-oriented Barangay Information Management System using Django/DRF,
React/TypeScript, PostgreSQL, and an optional GeoDjango/PostGIS runtime for
verified housing locations.

The current increment includes staff authentication, versioned profiling
form definitions, resident/household API foundations, append-oriented provenance,
and a **Field planner** for preparing tomorrow's requirements workshop. Most
workspace screens remain synthetic demonstrations, not operational databases.
Do not enter real resident data until privacy, field, retention, access, and GIS
decisions are approved.
